# Stickers — Penpot plugin

Создаёт цветные стикеры (заголовок + текст) и вставляет их на холст как редактируемые
фигуры. Внешний вид и палитра цветов сняты напрямую с референс-скриншота.

## ⚠️ v2: архитектурный фикс после реального теста в Penpot

Первая версия собирала стикер как один SVG (фон + `<text>` с `<tspan>` для переноса строк
+ `<filter>` для тени) и вставляла его через `penpot.createShapeFromSvg()`. При реальном
тесте в Penpot вылезли два бага:

1. **Цвет фона не применялся** — карточка оставалась прозрачной.
2. **Текст превращался в кривые** — не редактируется, в панели слоёв видно `svg-text` как
   раскрываемую группу путей, а не текстовую фигуру.

Причина — не ошибка в генерации SVG, а фундаментальное ограничение самого Penpot: **SVG-импорт
текста через `createShapeFromSvg` исторически плохо поддерживается** (давние открытые issue в
репозитории Penpot: [#1532](https://github.com/penpot/penpot/issues/1532),
[#1688](https://github.com/penpot/penpot/issues/1688)) — текст либо не импортируется, либо
рендерится как кривые. Похоже, `<filter>`-ссылка в моём SVG дополнительно ломала парсинг
самого `<rect>`, из-за чего терялась и заливка.

**Фикс — полностью убрать SVG из этого плагина.** Теперь `plugin.js` создаёт фигуры
напрямую нативным API:
- `penpot.createRectangle()` + `.fills = [{fillColor}]` + `.borderRadius` — фон;
- `penpot.createText(content)` + `.fontFamily/.fontSize/.fontWeight/.fills/.growType` —
  заголовок и текст.

Это гарантированно редактируемые нативные фигуры Penpot — тот же путь, что использует сам
Penpot при создании фигур с панели инструментов.

## Что делает

1. Выбираете один из 6 цветов (yellow, red, green, blue, gray, purple — точные hex-значения
   взяты пипеткой из скриншота-референса).
2. Вводите заголовок и текст — превью обновляется вживую (обычный HTML/CSS, не SVG).
3. «Добавить стикер на холст» → `plugin.js` создаёт прямоугольник-фон + два текстовых поля,
   группирует их в одну фигуру.
4. Текст переносится **нативным текстовым движком Penpot** (`growType: 'auto-height'` с
   фиксированной шириной) — точнее любой ручной оценки по числу символов, и остаётся
   полностью редактируемым после вставки.
5. Каждый следующий стикер смещается по каскаду (+24px по x/y), чтобы не вставать поверх
   предыдущего; после 6 стикеров каскад зацикливается.

## Файлы плагина

```
manifest.json   — метаданные и permissions (только content:write)
plugin.js       — sandbox-скрипт: createRectangle/createText/group, каскадное позиционирование
index.html      — форма (цвет/заголовок/текст) + превью
styles.css      — оформление в духе Penpot UI Kit + стили HTML-превью стикера
ui.js           — палитра, оценка высоты карточки под текст, план стикера (без SVG)
icon.png        — иконка 56×56
```

## Как это устроено внутри

- **Никакого SVG.** `ui.js` не строит SVG-разметку вообще — только структурированный
  «план» (`buildStickerPlan`): цвет, текст, размеры, отступы. `plugin.js` превращает этот
  план в нативные фигуры напрямую.
- **`fontSize`/`fontWeight` — строки, не числа.** Так требует подтверждённый API Penpot
  (`text.fontSize = '20'`, не `20`) — расхождение с этим форматом было бы тихой ошибкой,
  поэтому в `plugin.js` везде явный `String(...)`.
- **Перенос текста — двухуровневый.** `ui.js` всё ещё оценивает перенос по числу символов,
  но **только** чтобы прикинуть высоту фоновой карточки заранее (нужно знать размер
  прямоугольника ДО того, как реальный текст отрендерится). Сам видимый на холсте текст
  переносится нативным движком Penpot (`growType: 'auto-height'`, фиксированная ширина) —
  он точнее любой оценки по символам и остаётся живым/редактируемым.
- **Превью — HTML/CSS, не SVG.** Раз сама вставка больше не использует SVG, отпала и
  причина строить SVG для превью — обычный `<div>` с инлайн-стилями показывает то же самое,
  с честным браузерным переносом текста.

## Ограничения v2 (честно)

- Оценка высоты фоновой карточки (`computeCardHeight`) всё ещё приближённая (по числу
  символов) — в редких случаях с очень «широкими» символами реальный текст Penpot может
  занять чуть больше или меньше места, чем предполагает фон. Сам текст при этом останется
  полностью читаемым и редактируемым — расхождение чисто визуальное (фон чуть выше/ниже
  нужного), не функциональное.
- Каскадное позиционирование хранится в памяти сессии плагина — при переоткрытии плагина
  каскад начинается заново с центра вьюпорта.
- Шрифт зафиксирован как `Work Sans` — если этого шрифта нет в проекте, Penpot применит
  фолбэк по своим правилам (не проверялось вживую).

## Установка

Как и любой Penpot-плагин, `manifest.json` должен быть доступен по публичному URL:

1. [Netlify Drop](https://app.netlify.com/drop) — перетащите папку, допишите `/manifest.json`.
2. Локально: `npx serve .` или `python3 -m http.server 4400`.
3. В Penpot: `Ctrl+Alt+P` → «Plugin manager» → вставить URL `manifest.json` → «Install».

## Тестирование

Реального Penpot-файла в этой песочнице нет (баг из v1 был найден и исправлен по вашему
живому тесту, не по моему), поэтому автоматические проверки покрывают то, что можно
проверить без реального Penpot:

- Палитра, оценка высоты карточки, структура «плана» стикера (без SVG-поля вообще) — 17
  проверок в Node без DOM.
- Полный UI-флоу (выбор цвета → HTML-превью → добавление → план без svg-поля → успех/ошибка)
  — 20 проверок через DOM-шим.
- `plugin.js` — 22 проверки с фейковым `penpot`: `createRectangle`/`createText` вызываются
  с правильными аргументами (включая то, что `fontSize` — строка), `fills` использует
  нативный формат `[{fillColor, fillOpacity}]`, `group()` собирает верный набор фигур
  (2 или 3 в зависимости от наличия текста), каскад, обработка отказа `group()`.

```bash
cd test
node run_logic.js       # палитра, оценка высоты, план стикера, без DOM
node simulate_flow.js   # полный UI-флоу через DOM-шим
node run_plugin.js      # plugin.js с фейковым penpot (createRectangle/createText/group)
```

**Важно:** сама структура вызовов (`fills`, `fontSize` как строка, `growType`, `resize()`)
проверена по официальным примерам из документации Penpot Plugin API, но реального рендера
в браузере с реальным Penpot эти тесты не заменяют — стоит проверить визуально после
установки, как и в этот раз.

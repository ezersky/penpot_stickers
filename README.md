# Stickers — Penpot plugin

Создаёт цветные стикеры (заголовок + текст) и вставляет их на холст как редактируемые
фигуры — текст можно менять прямо в макете после вставки, никакого растра. Внешний вид
и палитра цветов сняты напрямую с референс-скриншота.

## Что делает

1. Выбираете один из 6 цветов (yellow, red, green, blue, gray, purple — точные hex-значения
   взяты пипеткой из скриншота-референса, не подобраны на глаз).
2. Вводите заголовок и текст — превью обновляется вживую.
3. «Добавить стикер на холст» → карточка со скруглёнными углами, мягкой тенью, жирным
   заголовком и текстом ниже появляется на холсте через `penpot.createShapeFromSvg()`.
4. Каждый следующий стикер в рамках одной сессии плагина смещается по каскаду (+24px по
   x и y на каждый), чтобы не вставать точно поверх предыдущего; после 6 стикеров каскад
   зацикливается.

## Файлы плагина

```
manifest.json   — метаданные и permissions (только content:write — токены/выделение не нужны)
plugin.js       — sandbox-скрипт: createShapeFromSvg, каскадное позиционирование
index.html      — форма (цвет/заголовок/текст) + превью
styles.css      — оформление в духе Penpot UI Kit (тот же язык, что и в прошлых плагинах)
ui.js           — палитра, перенос текста по ширине, генерация SVG стикера
icon.png        — иконка 56×56
```

## Как это устроено внутри

- **Цвета и пропорции — не приблизительные.** Скриншот-референс был проанализирован
  программно (пипетка по пикселям): фон каждого цвета, отступы текста от края карточки,
  соотношение ширины/высоты — всё взято из реальных значений, а не подобрано на глаз.
- **Текст остаётся текстом.** Заголовок и тело стикера — обычные SVG `<text>`/`<tspan>`
  элементы; `createShapeFromSvg` превращает их в редактируемые текстовые фигуры Penpot, а
  не в кривые/растр.
- **Перенос текста по ширине** — оценка по количеству символов на строку (моноширинное
  приближение, с отдельным коэффициентом для заголовка и тела, т.к. у них разный размер
  шрифта). Высота стикера автоматически растёт, если текста больше, чем помещается в
  стандартный размер 340×160.
- **Каскадное размещение** — простой счётчик в памяти `plugin.js` (сбрасывается при
  переоткрытии плагина), без всякого стейт-менеджмента: следующая позиция = центр вьюпорта
  + (номер_по_модулю_6) × 24px по обеим осям.

## Ограничения v1 (честно)

- Перенос текста — оценка по символам, не измерение реальной ширины шрифта (в редких
  случаях с очень «широкими» символами строка может оказаться чуть длиннее расчётной —
  сам текст при этом останется читаемым и редактируемым, просто перенос не идеально точный).
- Каскадное позиционирование хранится в памяти сессии плагина, не на холсте — при
  переоткрытии плагина каскад начинается заново с центра вьюпорта.
- Только 6 цветов из референса, без кастомного color picker (сознательное сужение объёма
  под то, что показано на скриншоте).

## Установка

Как и любой Penpot-плагин, `manifest.json` должен быть доступен по публичному URL:

1. [Netlify Drop](https://app.netlify.com/drop) — перетащите папку, допишите `/manifest.json`.
2. Локально: `npx serve .` или `python3 -m http.server 4400`.
3. В Penpot: `Ctrl+Alt+P` → «Plugin manager» → вставить URL `manifest.json` → «Install».

## Тестирование

Реального Penpot-файла в этой песочнице нет, поэтому:

- Палитра (все 6 цветов сверены с образцами из скриншота), перенос текста, генерация SVG
  (включая рост высоты под длинный текст и XSS-безопасное экранирование) — 30 проверок в
  Node без DOM.
- Полный UI-флоу (выбор цвета → живое превью → добавление → успех/ошибка) — 18 проверок
  через DOM-шим.
- `plugin.js` — 12 проверок с фейковым `penpot`, включая каскадное позиционирование
  (проверен инвариант «позиция повторяется ровно через 6 вставок», а не жёстко захардкоженное
  число), присвоение имени фигуре по заголовку, и работу без `penpot.viewport` (защитный
  fallback).

```bash
cd test
node run_logic.js       # палитра, перенос текста, генерация SVG, без DOM
node simulate_flow.js   # полный UI-флоу через DOM-шим
node run_plugin.js      # plugin.js с фейковым penpot (каскад, позиционирование)
```
